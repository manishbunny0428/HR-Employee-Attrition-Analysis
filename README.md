# HR Employee Attrition Analysis

## Project Overview
This project analyzes employee attrition using Python to identify workforce trends and potential factors associated with employees leaving an organization.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset
The dataset contains 1,470 employees and 35 columns, including age, department, job satisfaction, overtime, salary, and attrition status.

## Key Findings
- Total employees: 1,470
- Employees who left: 237
- Active employees: 1,233
- Overall attrition rate: 16.12%
- Overtime group attrition rate: 30.53%
- Non-overtime group attrition rate: 10.44%
- Research & Development had the highest number of employees leaving.
- The 18–25 age group had the highest attrition rate in the age-group analysis.

## Project Analyses
- Dataset exploration and data information
- Employee attrition KPIs
- Department-wise attrition
- Overtime vs. attrition
- Job satisfaction vs. attrition
- Age group vs. attrition
- Numerical correlation heatmap

## Recommendations
- Monitor overtime and workload.
- Improve employee satisfaction.
- Review department-level retention patterns.
- Conduct regular employee feedback surveys.

## How to Run
1. Install Python.
2. Install dependencies using `py -m pip install -r requirements.txt`.
3. Run the analysis using `py main.py`.

## Conclusion
This project demonstrates how Python-based data analysis can help identify employee attrition patterns and support data-informed HR decisions.

*Note: These findings describe associations in the dataset and do not establish causation.*
